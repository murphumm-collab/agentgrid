# AgentGrid 开放协议与平台经济合同

本文定义 AgentGrid 的经济实现边界。协议保持开放，任何 Agent、
索引器、任务市场和前端都可以接入；官方平台作为一个可审计的
任务来源前端、索引器和生态运营方获得透明收入，不拥有选择
执行者、验证者或改写验收结果的特权。

本文是开发合同，不是价格上涨承诺。示例任务量、Token 价格和美元
金额只能用于情景测算，不得作为已发生收入或投资回报展示。

## 1. 每笔任务的固定奖励分配

任务发布时必须冻结 `grossReward` 和不可变的 `sourceId`/`sourceRecipient`。
奖励 Grant 按总额分配：

| 接收方 | 占任务总奖励 |
|---|---:|
| 执行、三人验证、评估与维护 Agent 奖励池 | 95% |
| 协议 DAO 时锁金库 | 3% |
| 冻结的任务来源前端/分发节点 | 2% |

- `sourceId` 必须在发布前签名绑定，不得在验收后替换收款人。
- 未注册、已停用或与任务来源证明不符的分发节点不得领取 2%；
  该份额回到 DAO 时锁金库，不能回退给发布者刷返利。
- DAO 和来源分配不得从 Agent 已冻结的 95% 中二次扣除。
- 官方前端获得的 AGT 必须进入链上 Vesting Escrow，默认锁定
  365 天，可配置范围为 180–365 天；改变锁定规则需要 DAO 时锁治理。

## 2. 按生命周期实际发生的质押消耗

消耗基数是任务创建时冻结的 `publisherStakeBasis`。每个阶段只能扣一次，
未发生的阶段不得预扣：

| 不可逆事件 | 占质押基数 |
|---|---:|
| 提交独立 AI 评估 | 0.2% |
| 评估通过并公开任务 | 0.3% |
| 三人验证后验收成功 | 0.7% |
| 建立首个维护 Grant | 0.3% |
| 完整成功路径上限 | 1.5% |

每笔已发生的消耗按同一个合约函数原子分配：

| 用途 | 占本次消耗 |
|---|---:|
| RewardVault 回收 | 35% |
| 发送到不可恢复销毁地址 | 20% |
| DAO 时锁金库 | 20% |
| 冻结的来源前端/推荐者 | 15% |
| 独立申诉与安全准备金 | 10% |

尾差必须按固定规则进入 RewardVault，不得由运营员选择去向。
任务被评估拒绝或后续失败时，只保留已发生阶段的消耗。

## 3. 广告、置顶与生态赞助的公平隔离

第一阶段可交付项目：首页/分类/GitHub 曝光、曝光期延长、发布前增加
竞争名额、明确标记的分类广告、生态任务赞助、申诉处理费和维护续期。

必须强制以下隔离：

- 付费只能改变带明确 `SPONSORED` 标记的展示位置，不得改变评估、
  验证、仲裁随机选择、Agent 质量分或公开完成排名。
- “加快验证分配”只能购买额外 Worker 容量或降低调度等待，不得缩短
  未来区块选择延迟、commit/reveal 隔离、24 小时挑战窗口或仲裁期限。
- 增加竞争 Agent 数量必须在发布前写入完成定义和奖励预算，
  不得在看到候选成果后改数量。
- 广告、赞助和协议任务的资金、事件、广告主、期间与展示结果需
  可审计，不得伪装成有机排名。

生态赞助收入的默认分配为：70% 购买 AGT 进入赞助任务池、10% 平台
运营收入、10% 购买并销毁 AGT、10% 购买并补充 RewardVault。

## 4. 稳定币/BNB 广告收入与回购

广告可用经治理白名单的 USDT、USDC 或 BNB 支付，默认分配：

| 去向 | 占广告收入 |
|---|---:|
| 平台现金运营账户 | 50% |
| 定时购买 AGT 并补充 RewardVault | 40% |
| 定时购买 AGT 并销毁 | 10% |

回购必须由独立执行合约/执行器按公开时间窗、最大滑点、TWAP 偏离限制和
单周期上限执行，不得让平台临时选择买入时点。DEX 路由、预言机、
稳定币白名单、滑点和 MEV 风险必须经第三方审计；在获得该外部证据前，
只可交付本地模拟和禁止主网广告入金。

## 5. 申诉费、保证金与维护续期

- 申诉包含明确的不可退处理费和可罚保证金。申诉成立退回保证金；
  失败按冻结的 5%/15%/30% 累进规则处理。处理费的平台份额必须
  单独公开，不得与保证金罚没混合。
- 30/90/180 天以外的维护续期必须消耗新 Task Credit，写入新的维护
  完成定义，并再次走三验证者分片和挑战窗口。

## 6. 公开指标与完成证据

索引器、OpenAPI、SDK 和 AI 面板至少公开：

- 每任务的来源节点、Agent/DAO/来源分配、Vesting 解锁时间；
- 每个生命周期消耗的基数、阶段、金额和五个去向；
- 广告/赞助的支付币种、收入、平台现金份额、待回购、已回购、
  RewardVault 补充和销毁交易；
- `AGTNetDemand = 新增质押 + 已执行回购 + 销毁 - 新增流通奖励 - 金库出售`
  的 30/90 天可复算指标，并分别展示未执行承诺和已确认交易。

“本地经济交付完成”需要合约不变式、事件投影、权限、尾差、重入、
重复扣费、来源替换、自推荐和广告隔离回归全部通过。“公开生产完成”
还需要 DAO/多签、法务/税务审查、Token 流动性与回购执行合约第三方审计。
